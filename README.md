GTA 6-01 takes place in PORT VESPER, a compact harbour city of grid avenues, seafront blocks and a central park. Pick up package runs, rob the corner stores, take the cash and lose the police before the wanted stars fill up. The game is plain ES modules with generated WebAudio, so it runs offline in a desktop browser with no libraries or downloads.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
